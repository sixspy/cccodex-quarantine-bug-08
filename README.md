## 满舱闸（甲路·审计账册）

满舱当刻把**舱码 + 当刻水位指纹**（`sha256(舱码|占用/容量|占用行集合)`）一次性钉进
`cabin_full_gates` 落点行；抓取/入舱链路只读账册：

- 满舱且无落点行 → 拒（白话报错，禁止再塞件）
- 落点指纹与当刻水位偏移 → 拒（禁止清洗入库）
- 同一舱活动落点唯一，`BEGIN IMMEDIATE` + 唯一约束串行，两侧同抢只成一笔，拒绝回刷
- 仅甲路一条读轨（`cutover_book`）；双写归档/新水位旗轨已拆除，不并存
- 舱位页亮满舱芯片与水位值，抓取页挂水位条，对账页挂水位摘要，设置页只展满舱口径
